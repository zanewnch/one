## 情境與目標

說明使用情境、功能解決的問題，以及它在一次問答請求中負責哪一段。

## 學習重點

列出本次必要的概念，並用簡短 C# 對照說明陌生的 Java 或 Spring 語法。

## 任務範圍

列出輸入、回傳型別、責任所在、必要的介面變更及本次不需處理的功能。路徑和符號必須先查證；若依賴前一份作業，引用其已完成契約。

## 步驟提示

依實作順序給出可操作步驟與查閱位置。每步說明預期觀察到什麼，保留程式實作給學習者；參考程式若有不同目的，說明不應照搬的部分。

## 方法說明

交付時回答：

1. 修改了哪些檔案，各自負責什麼？
2. 輸入經過哪些步驟，最後得到什麼輸出？
3. 為什麼選擇這些型別與責任邊界？
4. 失敗如何傳遞，資源由誰管理？
5. 執行了哪些檢查，各自結果如何？
6. 還有哪些未完成或不確定的部分？

附上實際命令與輸出。Codex 依契約、結果及方法說明 review；有具體缺口就保持待修正，全部符合且學習者理解後才標記完成。
